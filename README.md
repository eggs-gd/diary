# Attention Journal (觀明)

Product-cycle repository for **Attention Journal** — not a diary. A tool for capturing what
catches your attention and returning later to see it more clearly.

The app lives in [`diary/`](./diary) — a SvelteKit static app shipped primarily as a
**PWA** ([journal.eggs.gd](https://journal.eggs.gd)), and wrapped with Capacitor for
iOS / Android. See its [README](./diary/README.md) for development and architecture, and
[`STORYBOARD.md`](./diary/STORYBOARD.md) for the product concept.

The repository root holds product-cycle material around the app — App Store assets,
descriptions, notes.

```sh
cd diary
yarn install
yarn dev
```
