# Журнал уваги (Attention Journal)

Репозиторій для продуктового циклу «Журнал уваги».

Клієнтський застосунок живе в [`diary/`](./diary): SvelteKit static app, Capacitor і
Firebase Analytics.

Корінь репозиторію лишається вільним для App Store матеріалів, описів, бекенду та інших
супутніх частин продукту.
